# Lonviato Ads API Privacy Notice

Shenzhen Jingju E-commerce Co., Ltd. operates Lonviato Ads API as an internal tool for reviewing advertising performance.

The tool uses Amazon authorization to read data from authorized Lonviato advertising accounts. This may include advertising account identifiers, campaigns, keywords, search terms, and metrics such as impressions, clicks, spend, and attributed sales. The tool uses this information for internal reporting and analysis.

API credentials and advertising reports are kept in the authorized work environment. This public page hosts the privacy notice only. Access to advertising data is limited to authorized users and the tools they use to perform the analysis.

For questions about data handling or to request removal of locally retained reports, contact jingju.design@gmail.com.
